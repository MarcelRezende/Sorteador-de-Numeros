# 🟣 Numbers — Sorteador de Números

**Sorteie números de forma rápida, simples e personalizada!**

O Numbers é uma aplicação web desenvolvida com HTML, CSS e JavaScript, que permite realizar sorteios de números dentro de um intervalo definido pelo usuário. Com uma interface moderna e intuitiva, o projeto oferece praticidade e personalização em cada sorteio.

## ✨ Funcionalidades

- 🔢 **Intervalo personalizado:** defina os valores mínimo e máximo para o sorteio.
- 🎲 **Quantidade de números:** escolha quantos números deseja sortear.
- 🚫 **Não repetir números:** opção para evitar números duplicados no mesmo sorteio.
- ⚡ **Resultado instantâneo:** visualize os números sorteados diretamente na tela.
- 🌙 **Design moderno:** interface com tema escuro e detalhes em roxo.
- 📱 **Responsividade:** adaptação para diferentes tamanhos de tela, conforme implementado no projeto.

## 💡 Como utilizar

1. Informe a quantidade de números que deseja sortear.
2. Defina o intervalo numérico desejado.
3.Ative ou desative a opção Não repetir número.
4.Clique no botão Sortear.
5.Confira os resultados apresentados na tela.
6.Quando a opção de não repetir números estiver ativada, o intervalo deverá conter números suficientes para atender à quantidade solicitada.
